# FocusRaid

FocusRaid is a small, original pixel world where real focus sessions help restore a blocked woodland path. Walk home, sit at your desk, finish a session, then carry the energy you earned back into the world.

This is an early playable build. I am making it because a focus timer feels more inviting when the time you put in changes a place you care about.

## Run locally

You need Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To check a production build, run `npm run build` and `npm run preview`.

## Project notes

- Stack: React, TypeScript, Vite, Canvas, CSS, browser localStorage. No account or server is required.
- Hackatime project name: `focusraid` via `.wakatime-project`.
- Do not commit credentials or `.env` files.
