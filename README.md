# FocusRaid

FocusRaid will be a cozy, original pixel world where real focus sessions help restore a woodland path. The plan is to walk home, use a desk to focus, and spend the energy earned to change the world.

**Current state:** project setup only. The playable game has not been built yet.

## Run locally

You need Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. It currently shows a placeholder screen. To check the scaffold build, run `npm run build` and `npm run preview`.

## Project notes

- Planned stack: React, TypeScript, Vite, Canvas, CSS, browser localStorage. No account or server is required for the first playable version.
- Hackatime project name: `focusraid` via `.wakatime-project`.
- Do not commit credentials or `.env` files.

## Before coding for Pixl

1. Open this folder in VS Code with the official Hackatime Time Tracker extension enabled.
2. Do a few minutes of genuine editing, then check your Hackatime dashboard for a `focusraid` project and real recorded time. Agent-created files do not prove your editor is recording your own work.
3. Register FocusRaid in Pixl and link [this public repository](https://github.com/therealprodigy/focusraid) to the `focusraid` Hackatime project. Do not select another project's time.
4. Build and commit in real milestones. Journal what you actually did after each work session.
