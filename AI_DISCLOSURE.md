# AI assistance

FocusRaid is an AI-assisted project. The project owner chose the focus-game concept, the magical-school mood, the VS Code workflow, and the direction of the writing.

Codex helped research comparable products, plan the first playable loop, write and review source code, draw original pixel characters and scenery in Canvas code, draft dialogue and documentation, and create automated tests. The not-ai writing skill was used to remove vague prose and keep claims tied to the work performed. It does not establish human authorship.

The first two rooms use code-drawn artwork rather than downloaded game sprites or generated image files. They are original designs, but they were made with AI assistance and should not be described as hand-drawn by the project owner.

All implementation edits in this development phase were entered through VS Code. Automated work and elapsed session time are not a claim of eligible human coding time. Any Pixl journal or time entry should accurately distinguish the owner’s work from AI assistance.

As of 8 October 2026, 20 automated tests and a production build passed. Browser playtesting, public deployment, and Pixl submission were not verified.
