# Release notes and what remains

The current update expands Greenvale east across a repairable bridge. It adds Whispering Garden, a glasshouse, an orchard, five discoveries, five more missions, clothing presets, coffee, longer streak milestones, local-time lighting and optional encouragement.

The established timer still supports 1–720 minute intervals and 1–12 rounds. Shared rooms, local backup recovery, audio, the shop, custom 404 and privacy/storage/terms pages remain part of the game.

## Before calling this release finished

Run the checks in TEST_PLAN.md, including mobile layout and a real two-device room. Keep the manual boxes unchecked until someone performs them. Check the public deployment after pushing source changes; this repository does not automatically deploy from GitHub.

## Later, if the town needs them

A library interior, more resident schedules and account-based cloud saves would each need separate design and migration work. Combat and equipment are not implemented. Adding another screen is less useful than improving a walk, a conversation or a session that already exists.
